# ОДО — онлайн документооборот

Хранилище документов, видео и ссылок с деревом **объектов → групп → разделов** (вкладываются друг в друга как папки на компьютере), полнотекстовым поиском, просмотром прямо в браузере, комментариями и журналом действий.

## Возможности

- **Объекты, группы, разделы** любой вложенности: создаются, переименовываются, перемещаются друг в друга.
- **Массовая загрузка**: перетащите сотни файлов или целую папку с подпапками, структура повторится. Файл до **5 ГБ** (настраивается). Загрузка идёт кусками по 16 МБ, 4 файла параллельно, с **докачкой** после обрыва связи.
- **Просмотр на сайте**:
  - PDF;
  - Word / Excel / PowerPoint / ODT / RTF — автоматически превращаются в PDF;
  - видео любых форматов (MP4, MOV, MKV, AVI, WMV…) — играет сразу и перематывается, файл **не скачивается целиком**. Несовместимые форматы сами перекодируются в MP4;
  - изображения, аудио, текстовые файлы, YouTube-ссылки.
- **Поиск** по названиям, описаниям, **тексту внутри PDF и Office-документов**, ссылкам и комментариям. ⌘K / Ctrl+K в любом месте.
- **Кто загрузил**: имя автора на каждой карточке, в списке, в поиске и в информации о файле.
- **Журнал действий** (только администратор): кто и когда скачал, открыл, загрузил, изменил, переместил, удалил, прокомментировал, входы в систему, IP-адрес. Фильтры по человеку и типу действия; у каждого файла своя история. Записи сохраняются и после удаления файла.
- **Роли**:
  - *Администратор* — всё, плюс пользователи и журнал;
  - *Редактор* — добавляет, изменяет и удаляет;
  - *Наблюдатель* — смотрит и комментирует.
- Вход **по логину**. Светлая и тёмная тема.
- **Мобильная версия** в стиле iOS: нижние вкладки, меню действий шторкой по долгому нажатию, свайп между файлами, постраничный просмотр PDF и Office (PDF.js), загрузка прямо с камеры. Сайт можно установить на телефон как приложение.

### На телефоне

Откройте адрес ОДО в Safari (iPhone) или Chrome (Android), затем «Поделиться» → **«На экран „Домой“»** (Android: ⋮ → «Добавить на главный экран»). Появится иконка ОДО, сайт будет открываться без адресной строки, как приложение.

- **Долгое нажатие** на файл или папку открывает меню: открыть, выбрать, скачать, изменить, переместить, удалить.
- **«Выбрать»** включает режим выбора: касаниями отмечаете несколько файлов, затем «Переместить» или «Удалить».
- **Загрузить → «Снять фото или видео»** — съёмка прямо с объекта сразу в нужный раздел.
- В просмотре файлы листаются **свайпом**, кнопка «Информация» внизу открывает сведения, историю и комментарии.

## Запуск на ноутбуке (Mac / Windows / Linux)

### 1. Один раз: установить Docker Desktop

Скачайте с https://www.docker.com/products/docker-desktop/ и запустите. В настройках включите
**«Start Docker Desktop when you sign in»**, чтобы ОДО поднимался сам после перезагрузки ноутбука.

### 2. Первый запуск

```bash
cd ~/Desktop/ODO
cp .env.example .env        # затем откройте .env и смените SECRET_KEY, POSTGRES_PASSWORD, ADMIN_PASSWORD
./odo.sh start
```

Первый запуск занимает 5–10 минут: скачиваются образы (около 2 ГБ). Последующие — секунды.

Скрипт покажет адреса:

```
ОДО запущен:
  На этом компьютере:   http://localhost:8080
  С других устройств:   http://192.168.0.112:8080   (в той же сети Wi-Fi)
```

Войдите с логином `admin` и паролем `ADMIN_PASSWORD` из `.env`. Затем в разделе **«Пользователи»** создайте аккаунты сотрудникам.

### 3. Повседневные команды

| Команда | Что делает |
|---|---|
| `./odo.sh start` | запустить (или применить изменения кода) |
| `./odo.sh stop` | остановить (данные сохраняются) |
| `./odo.sh status` | что запущено и по каким адресам открывать |
| `./odo.sh logs` | логи (Ctrl+C — выйти) |
| `./odo.sh backup` | резервная копия базы и файлов в `backups/` |
| `./odo.sh restore backups/odo-…` | восстановить из копии |

Контейнеры запущены с `restart: unless-stopped`: если Docker Desktop стартует при входе в систему, ОДО поднимется сам.

### Как это работает

```
 Браузер / телефон
        │  http://ноутбук:8080
        ▼
 ┌──────────────┐  /api/*   ┌───────────────┐      ┌────────────┐
 │ web (nginx)  │ ────────▶ │ backend       │ ───▶ │ db         │
 │ интерфейс,   │           │ Django: права,│      │ PostgreSQL │
 │ отдача видео │ ◀──────── │ загрузки,     │      └────────────┘
 │ и файлов     │ X-Accel   │ поиск, журнал │             ▲
 └──────┬───────┘           └───────────────┘             │
        │ читает файлы                                     │
        ▼                   ┌───────────────┐      ┌──────┴─────┐
   ./data/files  ◀───────── │ worker        │ ───▶ │ gotenberg  │
                 превью,    │ ffmpeg, PDF,  │      │ LibreOffice│
                 MP4, текст │ миниатюры     │      │ Office→PDF │
                            └───────────────┘      └────────────┘
```

1. Загрузка: браузер режет файл на куски по 16 МБ и отправляет в `backend`. При обрыве продолжает с последнего куска.
2. После загрузки `worker` в фоне делает миниатюру. Видео перекодирует в MP4 или оптимизирует под быстрый старт, Office-документ превращает в PDF (через `gotenberg`), а текст извлекает для поиска.
3. Просмотр: `backend` проверяет права и пишет в журнал, затем передаёт отдачу файла `nginx`. Тот стримит файл с диска с поддержкой перемотки.

Все данные лежат в папке **`./data`**: `data/postgres` — база, `data/files` — файлы.

### Доступ с других устройств

- **В той же Wi-Fi-сети** (офис, дом): открывайте `http://IP-ноутбука:8080` — адрес показывает `./odo.sh status`. Если macOS спросит про входящие подключения, нажмите «Разрешить». Ноутбук не должен засыпать: «Настройки → Аккумулятор → Параметры → Не переходить в режим сна…».
- **Из интернета**: проще всего через Cloudflare Tunnel или Tailscale, без белого IP и проброса портов. Для постоянной работы лучше перенести ОДО на сервер (см. ниже) и поставить домен с HTTPS.

## Перенос на сервер или другой ноутбук

**Через резервную копию (надёжно):**

```bash
./odo.sh backup                                 # создаст backups/odo-ДАТА/
# скопируйте папку проекта и backups/odo-ДАТА на новую машину, затем:
./odo.sh restore backups/odo-ДАТА
```

**Целиком:** `./odo.sh stop`, скопируйте всю папку `ODO` (вместе с `data/` и `.env`), на новой машине `./odo.sh start`.

## HTTPS и домен

Поставьте перед ОДО прокси с сертификатом (Caddy, nginx, Traefik) на порт `HTTP_PORT` и добавьте в `.env`:

```
COOKIE_SECURE=true
CSRF_TRUSTED_ORIGINS=https://odo.example.com
```

Во внешнем прокси разрешите тело запроса не меньше 64 МБ и увеличьте таймауты.

## Разработка без Docker

```bash
# бэкенд
cd backend
python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
export DATABASE_URL=postgres://USER@localhost:5432/odo DEBUG=true
python manage.py migrate && python manage.py ensure_admin
python manage.py runserver            # :8000
python manage.py run_worker           # в соседнем терминале (нужны ffmpeg и poppler)

# фронтенд
cd web && npm install && npm run dev  # http://localhost:5173
```

## Структура

```
backend/              Django
  core/models.py      User (роли, вход по логину), Folder, Item, Comment, Upload, Activity (журнал)
  core/views.py       JSON API: вход, папки, документы, загрузка кусками, поиск, журнал
  core/processing.py  обработка файлов (ffmpeg, pdftotext, Gotenberg)
web/                  React + Vite, nginx.conf
  src/components/     интерфейс: панель, папки, просмотр, поиск, пользователи, журнал
  src/uploads.jsx     очередь загрузок с докачкой
odo.sh                управление: start / stop / status / logs / backup / restore
scripts/              backup.sh, restore.sh
```
